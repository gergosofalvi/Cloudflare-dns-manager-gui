# Cloudflare DNS Manager - Weboldal

Ez a mappa tartalmazza a projekt statikus, animált, modern weboldalát.

## Futatás Dockerből

```sh
docker compose up --build
```

Ezután a weboldal elérhető lesz a http://localhost:8080 címen.

- A weboldal automatikusan betölti az aktuális verziót és letöltési linket az update.json alapján.
- A logók a static mappában találhatók.
- Fő színek: narancs (#EF7C17), szürke (#6F7375), sötét háttér.
